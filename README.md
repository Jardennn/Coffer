# Coffer - MVP

This is a CLI prototype built in Python to validate the core logic of Coffer before porting it to C#.

It is not the main project. The full C# implementation lives on the `dev` and `main` branches.

## Running it
```bash
python main.py
```

## Status

Still under development, have the pre-flight checkers setup but not the core backup logic. After I get the core logic done, I'll move onto adding in configs.
